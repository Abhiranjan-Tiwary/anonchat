# 🚀 AnonChat

**AnonChat** is a modern real-time anonymous social platform built for students and communities. Users can connect, chat, create profiles, send friend requests, exchange direct messages, and participate in topic-based conversations while maintaining privacy and security.

## 🌐 Live Demo

Website: https://anonchat-5fbw.onrender.com

---

## ✨ Features

### 👤 Authentication

* Email & Password Authentication
* Google Login
* Facebook Login
* Secure Session Management
* Password Reset & OTP Verification

### 💬 Real-Time Chat

* Instant Messaging using Socket.io
* Typing Indicators
* Message Delivery & Seen Status
* Emoji Reactions
* Media Sharing Support

### 🤝 Social Features

* User Profiles
* Friend Requests
* Friends List
* Direct Messaging
* Notifications

### 🏫 Community Rooms

* Topic-Based Chat Rooms
* College & Campus Discussions
* Events & Announcements
* Community Engagement

### 🛡️ Security & Moderation

* User Reporting System
* Admin Dashboard
* Content Moderation Tools
* Secure Authentication
* Protected Routes
